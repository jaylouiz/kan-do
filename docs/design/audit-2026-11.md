# UI Audit — 2026-11

Audit of the built UI of the board, the task sheet, `/statistics`, the settings pages, the trash, the day-close dialog/drawer and the new-day recap for visual coherence, reuse and code solidity (issue #549, part of #548). It changes no layout and no functionality. Its second output is groundwork for the coming visual redesign (on hold): the inventory in Part 1 names the canonical component or pattern for each recurring UI job.

- **Audited commit:** `2bc0f398` (`main` after #538). Every `file:line` below exists on that commit.
- **Mode:** Operate. Light only (dark mode was removed, backlog X1). Surfaces not in scope: `pages/styleguide.vue`, `pages/error-test.vue`, `pages/dnd-sample.vue`, `components/prototype/`.
- **Method:** the four passes of the issue (inventory, code solidity, rendered review, Impeccable critique and audit) and a synthesis. `rg` sweeps, `wc -l`, Playwright (Chromium, `?seed=local|demo|dayclose|newday`, 1280×900 and 390×844, touch emulation at 390), the Impeccable detector (source and rendered), the existing axe specs. The screenshots are attached to the PR, not the repo; each is described in words in "Before-state screenshots".
- **Dedupe:** open entries of `docs/design/backlog.md` are referenced, not re-filed (P4 #30 and P5 #65 are still open and out of this audit's scope). Findings from `docs/design/audit-2026-10.md` that are marked done there were re-checked in the current UI and are not repeated (F1–F14 hold: the `a11y.spec.ts` run below passes).
- **Findings:** IDs `U1`–`U20`, severity P0–P3 (P0 blocks a task, P1 WCAG AA or major, P2 minor with a workaround, P3 polish). No P0 or P1 exists.

- **Settings, consistency 2:** three tab looks (U9), an orange warning icon as an empty state (U11), headings off the display role (U8), hand-rolled notices (U10).

**Design specificity verdict:** pass. The board, the app bar, statistics and the recap read as one product (Quiet Desk). The weak spots are the seams: the day-close secondary buttons, the sticky translucent page header, the Notion settings page and the topics tabs.

**What's working:** the verdict-first statistics page with disclosure tiles; the recap composition; the in-card and in-slot flows; one app bar on every page; no status colour used as decoration on the surfaces that were redesigned; tokens: no raw hex or palette class found by the detector.
