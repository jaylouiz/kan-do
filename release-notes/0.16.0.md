## Highlights

### de

- **Schonender für deinen Akku.** Steht dein Board still, arbeitet kan-do kaum noch im Hintergrund, auch wenn in Jetzt eine Aufgabe läuft.
- **Größere Karten auf dem Handy.** Aufgaben sind auf kleinen Bildschirmen besser zu erkennen.
- **Diverse UI-Feinabstimmungen.** Für eine reibungslose und verständliche Bedienung.

### en

- **Easier on your battery.** When your board is at rest, kan-do does hardly any background work, even with a task running in Jetzt.
- **Larger cards on your phone.** Tasks are easier to make out on small screens.
- **Assorted UI refinements.** For smoother and clearer use.

## Fixes

- A resting board rests: no per-tick fill easing, focus overlay measured only when the Jetzt card may have moved, page state via attributes instead of `:has()`, Todoist SDK loaded on first use (#291).
- Each Keychain entry is read once per session; developer feedback can use the GitHub CLI login; the feedback token row shows only for a stored token (#284).
- Command palette "Verschieben" heading masked in feedback screenshots; no check icon before the Erledigt title; phone cards 308 × 140 (#283).
- Relaunch after an update without a second Dock icon, effective from the next update after this one (#277).
